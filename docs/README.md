# Docs index

These documents contain research, historical trade notes, and standing implementation notes for the live Simple Trader.

- research/ - evidence and dated pre-market research.
- journal/trade-journal.md - historical trade journal and lessons.
- memory/ - standing implementation preferences and historical lessons.
- setup/ - environment and GitHub connection notes.
- robinhood-tool-matrix.md - equity-focused Robinhood MCP tool inventory.

Historical notes do not override the current root-level CLAUDE.md, PROMPT.md,
SKILL.md, STRATEGY.md, or live broker response. Those files are the current
source of truth.

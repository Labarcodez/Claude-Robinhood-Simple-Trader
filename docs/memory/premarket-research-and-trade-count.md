The trader should research pre-market catalysts and unusual activity when the
session permits, then carry that context into the trading day.

There is no arbitrary daily trade-count cap. However, the pre-market watchlist
is a priority list, not an exclusive universe: current live evidence can
introduce a new candidate at any time.

Use actual Robinhood account, market, quote, historical, technical, tradability
and order-book data plus any already-available research connector. Never invent
a catalyst or require an unavailable tool.

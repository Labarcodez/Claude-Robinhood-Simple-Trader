Historical lesson: the user prefers active day trading, prompt recognition of
failed setups, and taking gains when the evidence supports an exit.

This is not a fixed percentage target, fixed time stop, or mandatory breakeven
rule. Current exits are governed by STRATEGY.md: structure, VWAP, volume,
execution quality, fresh information, and the setup's invalidation/trailing
reference.

Do not convert this historical preference into a hard trading limit.

# Standing rules and preferences

These files contain historical lessons and implementation preferences. They are
not a second trading policy.

Current source of truth, in order:
1. live Robinhood broker/account/order response;
2. CLAUDE.md and PROMPT.md;
3. STRATEGY.md;
4. SKILL.md;
5. dated journal/research/memory notes.

Do not resurrect obsolete fixed targets, time stops, trade caps, watchlist-only
rules, or other limits from historical notes unless they are explicitly present
in the current strategy.
